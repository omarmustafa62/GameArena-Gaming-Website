# GameArena — Gaming & Esports Website

A responsive gaming and esports website concept built around game discovery, tournament content, team profiles, and contact information.

## Highlights
- Gaming-focused landing page and navigation
- Latest games showcase with a Bootstrap carousel
- What-we-do and team sections
- Tournament and community-oriented content
- Responsive navigation and layout
- Contact form interface

## Built With
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap JavaScript
- Font Awesome

## Run Locally
Clone the repository, then open `GameArena-Gaming-Website/index.html` in a browser.

## Project Structure
- `GameArena-Gaming-Website/index.html` — page markup
- `GameArena-Gaming-Website/styles/` — Bootstrap, custom, and responsive styles
- `GameArena-Gaming-Website/js/` — Bootstrap and icon scripts
- `GameArena-Gaming-Website/images/` — visual assets
- `GameArena-Gaming-Website/webfonts/` — icon fonts

> The contact form is a frontend UI; no form-submission backend is included.
