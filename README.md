# GameArena – Gaming Website

A gaming and esports website concept showcasing games, tournaments, teams, and community-focused content.

## Features
- Gaming-themed landing page and navigation
- Latest games showcase
- Team and service sections
- Tournament and contact-oriented content
- Responsive layout

## Built With
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Run Locally
1. Clone this repository.
2. Open `GameArena-Gaming-Website/index.html` in your browser.

## Project Structure
The website source is inside `GameArena-Gaming-Website/`. Styles, scripts, images, and web fonts are organized in separate folders.
